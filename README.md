# Estudos de Programação em C 💻

Olá! Seja bem-vindo ao meu repositório de estudos.

Este espaço foi criado para armazenar minhas atividades, exercícios e desafios desenvolvidos durante meu aprendizado em linguagem C.

## 📚 Conteúdos estudados

- Fundamentos da linguagem C
- Variáveis e tipos de dados
- Estruturas condicionais (if, else e switch)
- Estruturas de repetição (for, while e do-while)
- Funções e modularização
- Parâmetros e retornos
- Operações matemáticas
- Lógica de programação

## 📁 Organização

- `01-fundamentos`: exercícios básicos.
- `02-condicionais`: estruturas condicionais.
- `03-repeticao`: estruturas de repetição.
- `04-funcoes`: funções e modularização.
- `05-projetos`: pequenos projetos desenvolvidos em C.

## 🛠️ Tecnologias

- Linguagem C
- GCC
- CLion / Visual Studio Code
- Git e GitHub

## 🎯 Objetivo

Praticar lógica de programação, desenvolver minhas habilidades e registrar minha evolução como estudante de Ciência da Computação.
